# Risu-BEAT

RisuAI 안에서 즐기는 리듬게임 플러그인

## 설치

1. 이 저장소의 `Risu-BEAT.js` 파일을 받습니다.
2. RisuAI 설정의 플러그인 메뉴에서 파일을 추가합니다. (플러그인 API 3.0)
3. 채팅 화면 오른쪽 위의 **RB** 버튼이나 햄버거 메뉴의 **Risu-BEAT**로 실행합니다.

기본곡은 처음 플레이할 때 이 저장소에서 음원을 받습니다. 한 번 받은 곡은 기기에 저장되어 다음부터는 바로 재생됩니다.

## 파일 구성

| 경로 | 내용 |
|---|---|
| `Risu-BEAT.js` | 플러그인 본체 |
| `assets/` | 기본곡 · 배경 음악 데이터 |

## 이용 안내

플레이는 자유롭게 하셔도 됩니다. 코드, 음원, 이미지의 수정 · 재배포 · 다른 용도 사용은 허용하지 않습니다.
